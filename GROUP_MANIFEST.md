# Shiko LMS - Group Manifest

## Communication
- Discord for daily communication
- Meetings as needed during the project

## GitHub Branch Naming Conventions
- `feature/` - new functionality
- `fix/` - bugfix
- `assets/` - for resources
- `refactor/` - code restructuring without behavior change
- `docs/` - documentation

## Git Push Strategy
- Push to develop branch with pull request
- Review with group before merge
